# Prévia — Dra. Sabrina Peixoto

Prévia conceitual de landing page, feita a partir do perfil público da profissional.

**Não é uma publicação oficial.** Ainda não tem aprovação da profissional e não deve ser divulgada como página definitiva.

## Pendências antes de qualquer publicação

- Autorização de uso do retrato. A imagem é um estudo ampliado por IA a partir da foto pública de perfil; a semelhança precisa ser confirmada.
- CRM e dados profissionais em fonte oficial.
- Revisão da publicidade médica com a profissional.
- Endereço, horários e responsável técnico.

## Conteúdo
